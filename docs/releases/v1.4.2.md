## Windows code signing status — please read

**The Windows files in Gharmonize v1.4.2 do not carry a trusted Authenticode signature.** The SignPath Foundation production code-signing certificate is still pending. Self-signed test certificates are not used for this public release.

This applies to the Setup installer, the standalone Portable EXE, and the application executable inside the Portable Folder ZIP. Windows may display an unknown-publisher or SmartScreen warning; managed Windows security policies may block execution.

Download only from this repository's official Releases page and verify the published checksums and GitHub artifact attestations. The GPG-signed checksum manifest verifies release integrity but is **not** a Windows Authenticode signature. Do not disable Windows security protections or install a test certificate to run this release.

## What's improved

- Removed forced GPU acceleration disabling in the Linux AppImage. The explicit hardware-acceleration opt-out remains available.
- Kept managed FFmpeg and FFprobe available when NVIDIA NVENC is unavailable or incompatible, with software conversion still supported.
- Added runtime-tested stable FFmpeg compatibility candidates for older NVIDIA driver APIs, while preserving unrestricted master selection with a compatibility warning.
- Prevented packaged desktops from silently falling back to system FFmpeg/FFprobe and corrected displayed tool versions that previously appeared as `latest`.
- Unified packaged desktop application caches under `DATA_DIR/Cache`, without moving or deleting existing lowercase `cache` directories. On case-sensitive systems, missing managed tools download again at startup; Node and Docker retain their existing lowercase cache defaults.
- Honored configured `DATA_DIR` paths while keeping the existing environment-file and encryption-key locations unchanged.
- Improved music matching across artist credits, accented titles, and reasonable duration differences, and cleaned redundant combining dots in newly created playlist folder names.
- Preserved accurate MP3 duration metadata through conversion, retagging, and lyric embedding.
- Added graceful yt-dlp process termination and guarded cleanup of inactive PyInstaller temporary directories to reduce leftover extraction files.
- Updated Electron to 44.6.0, music-metadata to 12.0.0, dotenv to 18.0.6, express-rate-limit to 8.7.1, and proxy-addr to 2.0.8.

## Downloads

Container images are published separately to `ghcr.io/g-grbz/gharmonize:1.4.2` and `ghcr.io/g-grbz/gharmonize:latest` by the Docker workflow.
