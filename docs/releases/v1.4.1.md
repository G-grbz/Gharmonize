## Windows code signing status — please read

**The Windows files in Gharmonize v1.4.1 do not carry a trusted Authenticode signature.** The SignPath Foundation production code-signing certificate is still pending. Self-signed test certificates are not used for this public release.

This applies to the Setup installer, the standalone Portable EXE, and the application executable inside the Portable Folder ZIP. Windows may display an unknown-publisher or SmartScreen warning; managed Windows security policies may block execution.

Download only from this repository's official Releases page and verify the published checksums and GitHub artifact attestations. The GPG-signed checksum manifest verifies release integrity but is **not** a Windows Authenticode signature. Do not disable Windows security protections or install a test certificate to run this release.

## What's improved

- Reduced unnecessary Classic UI work by batching layout updates, ignoring duplicate job snapshots, and deferring hidden job-panel rendering.
- Bounded optional music metadata, cover-art, and lyrics requests so an unavailable provider cannot indefinitely delay conversion.
- Added per-track download and metadata timings to help identify slow stages.
- Fixed successful embed-only lyrics being reported as missing and corrected duplicate lyrics statistics.
- Improved Apple Music, Deezer, and Spotify matching for accented titles and video labels such as `(Clip Officiel)`, while preserving actual musical versions such as Live and Remix.
- Corrected fallback track numbering when only a subset of an Automix playlist is selected.

## Downloads

Windows Setup, Portable EXE, and Portable Folder packages are available alongside the Linux AppImage and its `.zsync` update metadata. Container images are published separately to `ghcr.io/g-grbz/gharmonize:1.4.1` and `ghcr.io/g-grbz/gharmonize:latest` by the Docker workflow.
