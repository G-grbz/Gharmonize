# Gharmonize v1.4.4

## Desktop tray icons

- Choose **Original**, **Dark**, **Light**, or **Automatic (system theme)** from the tray's right-click menu on Windows and Linux.
- Automatic mode uses a light icon on a dark system theme and a dark icon on a light system theme. On Windows, it follows the taskbar/system theme rather than the application theme.
- The selection is remembered across restarts, including startup directly in the tray. Monochrome icons include high-DPI representations, without creating an extra renderer or polling for theme changes.

## Job stages and timings

- Classic and YTLive job cards now show elapsed time and an on-demand **Stages and timings** view.
- Instrumented music workflows report per-track matching, download, metadata, artwork, conversion, lyrics, and retagging stages. Cached matches, failures, missing matches, retries, and cancellations are distinguished.
- Details are paginated, and completed measurements are saved with job history. Elapsed clocks do not generate background network requests.
- Refined Classic job-card layouts and timing dialogs for long titles, small screens, and light/dark themes.

## Video conversion

- Added optional black-border detection and cropping when transcoding with **automatic height**. The output is scaled using the detected content's aspect ratio.
- Detection checks several short samples and keeps the original frame when the result is inconclusive. It also respects preview clips and orientation settings.
- Improved re-encoded video/audio timelines by materializing timestamp gaps and delayed starts as frames/samples. Stream-copy modes retain their original timing; extracting raw tracks can still discard codec-delay metadata.

## Dependency updates

- Updated Electron to **44.9.3**, electron-builder to **26.18.0**, dotenv to **18.0.8**, and music-metadata to **12.2.3**.
- Refreshed dependency resolutions with security fixes for upload handling, HTTP parsing, URI handling, and development/build tooling.

## Windows code signing status — please read

**The Windows files in Gharmonize v1.4.4 do not carry a trusted Authenticode signature.** Self-signed test certificates are not used for this public release.

This applies to the Setup installer, the standalone Portable EXE, and the application executable inside the Portable Folder ZIP. Windows may display an unknown-publisher or SmartScreen warning; managed Windows security policies may block execution.

Download only from this repository's official Releases page and verify the published checksums and GitHub artifact attestations. The GPG-signed checksum manifest verifies release integrity but is **not** a Windows Authenticode signature. Do not disable Windows security protections or install a test certificate to run this release.

## Downloads

Windows Setup, Portable EXE, and Portable Folder packages are produced alongside the Linux AppImage and its `.zsync` update metadata by the automated release workflow. Container images are published separately to `ghcr.io/g-grbz/gharmonize:1.4.4` and `ghcr.io/g-grbz/gharmonize:latest` by the Docker workflow.
