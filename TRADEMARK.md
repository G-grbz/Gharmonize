# Gharmonize Name and Branding Policy

Gharmonize source code is distributed under the **GNU General Public License v3.0 (GPL-3.0)**. The GPL grants broad rights to copy, modify, and redistribute the covered source code under its terms.

Those software-license permissions do **not** grant permission to use the **Gharmonize** project name, logo, screenshots, or other project branding in a way that falsely suggests that a separate project, modified build, repository, website, or binary distribution is official, endorsed by, or affiliated with the original Gharmonize project.

## Acceptable references

You may truthfully describe a project as, for example:

- "a fork of Gharmonize"
- "based on Gharmonize"
- "derived from Gharmonize"

when that description is accurate, the original project is appropriately attributed, and the modified or independent project is clearly identified as **unofficial and unaffiliated**.

## Misleading use is not permitted

Please do not:

- present a separate or modified project as the official Gharmonize project;
- use **Gharmonize** as the primary identity of an unrelated distribution in a way likely to confuse users about its origin or maintainership;
- use the Gharmonize logo, screenshots, or branding to imply endorsement or official status that does not exist;
- claim or imply an affiliation with `G-grbz/Gharmonize` without permission;
- distribute unrelated binaries or redirect users to unrelated download sites while presenting them as official Gharmonize downloads.

If you distribute a modified version, the simplest way to avoid confusion is to use a distinct project name and state clearly that it is based on Gharmonize and is not an official Gharmonize release.

## Official project

The official project locations are:

- Repository: https://github.com/G-grbz/Gharmonize
- Releases: https://github.com/G-grbz/Gharmonize/releases

No third-party repository, website, or download service should be assumed to be official unless the official repository explicitly identifies it as such.

## Relationship to GPL-3.0

This branding policy is separate from the GPL-3.0 license covering the source code. It is not intended to restrict the rights granted by GPL-3.0 to copy, modify, or redistribute covered code. A downstream project can exercise those GPL rights while using distinct branding and accurately describing its relationship to Gharmonize.
